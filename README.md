# FilmBuff Android TV — 1.3.1

این بسته از فایل v1.2.3 ارسالی ساخته شده است. پلیر و ظاهر صفحهٔ اصلی همان فایل ارسالی است؛ فقط اجرای افقی، لانچر تلویزیون و فوکوس ریموت اضافه شده است.

لینک «دانلود مستقیم» از مسیر `/go?mode=browser` در مرورگر خارجی باز می‌شود. فایل‌های ثابت سایت در اپ قرار دارند؛ برای بارگذاری خود سایت بدون VPN دامنهٔ اصلی یا دامنهٔ جایگزین Worker باید در شبکهٔ ایران در دسترس باشد. `APP_BASE_URL` و `APP_FALLBACK_URLS` (چند آدرس HTTPS جداشده با ویرگول) را در GitHub Actions Variables تنظیم کن؛ آدرس‌ها باید به یک سایت متصل باشند. با VPN هم همان آدرس‌ها کار می‌کنند.

محتویات پوشهٔ FilmBuff، شامل پوشهٔ مخفی `.github`، را در ریشهٔ مخزن قرار بده. از Actions اجرای `FilmBuff TV signed Release` را انتخاب کن. در بخش Artifacts فقط APK امضاشدهٔ Release منتشر می‌شود؛ از کلید امضای موجود `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` (یا نام‌های `ANDROID_...`) استفاده می‌شود. برای به‌روزرسانی گوشی نسخهٔ قبلی، کلید باید دقیقاً همان کلید قبلی باشد.

تأیید واقعی باز شدن سایت و CDN روی اینترنت ایران به آزمون روی همان اینترنت نیاز دارد.

ساخت محلی Release هر دو نسخه موفق بوده است. خروجی محلی برای بررسی کامپایل بدون امضا ساخته شد؛ امضای نهایی APK در GitHub Actions با کلید قبلی انجام می‌شود. آزمون دستگاه واقعی، ریموت واقعی و اینترنت ایران انجام نشده است.
