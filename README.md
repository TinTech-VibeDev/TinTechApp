# FilmBuff Mobile 1.3.0 — ساخت Release

یک پروژه، دو اپ جدا: **FilmBuff Mobile** و **FilmBuff TV**. هر دو، سایت را در WebView نمایش می‌دهند و لینک `/play` را با پلیر داخلی Media3 باز می‌کنند. کد Worker و اسکرپرها در این پروژه تغییری نکرده است.

## قابلیت‌های جدید

- پلیر با کنترل‌های تازه، نوار زمان، انتخاب کیفیت و زبان صدا، سرعت پخش، اندازهٔ تصویر و محو شدن کنترل‌ها.
- زیرنویس با پنج رنگ آماده و رنگ دلخواه `#RRGGBB`، اندازهٔ متن، فاصله از پایین و پس‌زمینهٔ تیره. تنظیمات ذخیره می‌شوند؛ رنگ‌های داخلی ASS نیز از تنظیم کاربر پیروی می‌کنند.
- افزودن فایل **SRT، VTT، ASS و SSA** از انتخاب‌گر اندروید؛ حداکثر ۴ مگابایت. خواندن UTF-8، UTF-16 دارای BOM و Windows-1256 برای زیرنویس‌های قدیمی فارسی. فایل انتخابی در فضای خصوصی برنامه کپی می‌شود؛ مجوز دسترسی کامل حافظه درخواست نمی‌شود.
- پخش مستقیم با تعویض خودکار و محدود به مسیر سایت در صورت خطای اتصال؛ گزینهٔ انتخاب دستی مسیر نیز وجود دارد.
- رفع تشخیص اشتباه زیرنویس WebVTT برگشتی از `/api/source-subtitle` و `/api/player-subtitle`.
- رفع بارگذاری مجدد کل صفحه به خاطر خطای عکس یا فایل جانبی؛ بازیابی محدود اتصال، صفحهٔ خطای قابل کنترل و استفاده از کش عادی WebView.
- توقف پخش در پس‌زمینه، حفظ موقعیت هنگام بازیابی صفحه و تصویر در تصویر در گوشی‌های سازگار.
- وابستگی‌های ثابت HLS، Telegram SDK و قلم رابط داخل APK قرار گرفته‌اند؛ سایت برای دریافت این فایل‌ها به CDN خارجی وابسته نیست.

## نسخهٔ تلویزیون

مخصوص **Android TV، Google TV و دستگاه‌های سازگار با Android TV** با Android 7 یا جدیدتر است. برای سیستم‌عامل‌های Tizen سامسونگ یا webOS ال‌جی قابل نصب نیست؛ برای آن‌ها از اندرویدباکس استفاده کنید.

نسخهٔ TV آیکن و بنر در لانچر تلویزیون، حالت افقی، کارت‌ها و متن بزرگ‌تر، حاشیهٔ مناسب صفحه و فوکوس مشخص دارد. نسخهٔ گوشی و تلویزیون شناسهٔ متفاوت دارند و جداگانه نصب می‌شوند.

| دکمهٔ ریموت | کارکرد |
| --- | --- |
| جهت‌ها در سایت | جابه‌جایی بین کارت‌ها، دکمه‌ها و لینک‌ها |
| OK در سایت | باز کردن مورد انتخابی؛ روی ورودی جست‌وجو کیبورد دستگاه باز می‌شود |
| Back در سایت | بستن پنجرهٔ باز، سپس بازگشت به صفحهٔ قبل |
| چپ/راست هنگام مخفی بودن کنترل‌های پلیر | ۱۰ ثانیه عقب/جلو |
| بالا/پایین در پلیر | نمایش کنترل‌ها |
| OK روی دکمهٔ پخش | پخش/مکث |
| Menu در پلیر | تنظیم زیرنویس |
| Back در پلیر | ابتدا مخفی کردن کنترل‌ها، سپس خروج |

برای افزودن فایل زیرنویس از USB در تلویزیون، دستگاه باید انتخاب‌گر فایل سازگار با `ACTION_OPEN_DOCUMENT` داشته باشد. بعضی تلویزیون‌ها این انتخاب‌گر را ندارند؛ در این حالت پیام راهنما نمایش داده می‌شود. زیرنویس آنلاین و زیرنویس داخل ویدئو مستقل از این انتخاب‌گر کار می‌کنند.

اصلاح SDK: پس از جایگزینی `.github/workflows/build-apk.yml` و ثبت Commit جدید، **Run workflow** را بزنید. تنظیمات کلید امضا همان قبلی هستند.

## ساخت Release نسخهٔ گوشی با GitHub Actions

این ZIP کد کامل برای ساخت نسخهٔ **Mobile** است؛ APK امضاشده پس از اجرای موفق Actions تولید می‌شود. خروجی Debug جایگزین نمی‌شود.

1. ZIP را استخراج کنید. **محتویات داخل پوشهٔ FilmBuff** را در ریشهٔ ریپوی فعلی دارای کلید امضا جایگزین کنید؛ خود ZIP را به ریپو اضافه نکنید. پوشهٔ `.github/workflows` هم باید منتقل شود.
2. به **Actions → Build FilmBuff Mobile Release → Run workflow** بروید و شاخهٔ `main` را انتخاب کنید. اگر Push ساخت را شروع کرده، همان اجرا را دنبال کنید.
3. پس از سبز شدن اجرا، از **Artifacts → FilmBuff-Mobile-1.3.0-Release** خروجی را دانلود و ZIP آن را باز کنید. فایل `app-mobile-release.apk` قابل نصب است؛ AAB برای انتشار نیز همراه آن است.

اگر هر دو ZIP مجزا را در یک ریپو استفاده می‌کنید، ابتدا بستهٔ اول را جایگزین و خروجی آن را دریافت کنید؛ سپس بستهٔ دوم را جایگزین و دوباره بسازید. فایل workflow هر بسته مخصوص همان نسخه است. تنظیمات امضای ریپو با جایگزینی فایل‌های پروژه حذف نمی‌شوند.

چهار نام فعلی از **Secrets یا Variables** خوانده می‌شوند: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS` و `KEY_PASSWORD`. نام‌های معادل با پیشوند `ANDROID_` هم پشتیبانی می‌شوند؛ Secrets اولویت دارند. کلید جدید نسازید و کلید یا رمز را داخل کد نگذارید. تنظیمات ناقص، ساخت را با خطا متوقف می‌کند.

شناسهٔ گوشی: `ir.tintech.film`؛ تلویزیون: `ir.tintech.film.tv`؛ نسخهٔ هر دو `1.3.0` و کد نسخه `130` است. هر بسته کد مشترک پروژه را حفظ می‌کند و Actions فقط هدف انتخابی همین بسته را تولید می‌کند.

## اتصال با اینترنت ایران و با VPN

اپ اتصال مستقیم، مسیر جایگزین از طریق سایت، کش رابط و فایل‌های محلی را دارد؛ VPN روشن یا خاموش شرط اجرای برنامه نیست. **در دسترس بودن روی همهٔ اپراتورهای ایران تضمین نمی‌شود.** اپ نمی‌تواند دامنهٔ مسدود یا سرور از کار افتاده را به‌تنهایی قابل دسترس کند. آزمون واقعی روی اینترنت ایران و سخت‌افزار تلویزیون در محیط توسعه انجام نشده است.

آدرس پیش‌فرض فعلی:

`https://movie-search-bot.barmonn.workers.dev/menu`

اگر این آدرس روی یک شبکه باز نمی‌شود، دامنهٔ HTTPS قابل دسترس و متعلق به همین سرویس را روی Worker تنظیم کنید. در **Settings → Secrets and variables → Actions → Variables** ریپو، بدون Wrangler می‌توانید این متغیرها را بسازید:

| Variable | کاربرد |
| --- | --- |
| `APP_BASE_URL` | آدرس اصلی سایت، مثلاً `https://film.example.com/menu`؛ مثال را با دامنهٔ واقعی خود جایگزین کنید |
| `APP_FALLBACK_URLS` | حداکثر دو آدرس جایگزین **همین سرویس**، جداشده با کاما |

سپس Actions را دوباره اجرا کنید. اگر مقادیر را خالی بگذارید، آدرس پیش‌فرض حفظ می‌شود. داخل هر اپ، دکمهٔ **اتصال** نیز اجازهٔ وارد کردن حداکثر سه آدرس HTTPS را می‌دهد. مسیر و query صفحه هنگام تغییر آدرس حفظ می‌شوند. همهٔ آدرس‌ها باید نسخهٔ سازگار همان سایت باشند؛ انتقال خودکار نشست ورود بین دامنه‌ها انجام نمی‌شود.

در پلیر، گزینهٔ **اتصال → خودکار** ابتدا مسیر مستقیم را امتحان می‌کند و پس از خطای شبکه یا انتظار طولانی، یک بار از مسیر `/api/proxy-dl?u=...&force=1` روی سایت استفاده می‌کند. این endpoint باید در Worker فعال باشد؛ نسخهٔ Worker v273 تهیه‌شده برای این پروژه از آن پشتیبانی می‌کند. مسیر سایت لزوماً هر مشکل CDN یا قالب ویدئو را برطرف نمی‌کند. هیچ پراکسی عمومی یا نشانی ساختگی در برنامه قرار نگرفته است.

اتصال ناامن HTTP در WebView و رد کردن خطاهای گواهی TLS مجاز نیست. لینک ویدئوی HTTP در حالت خودکار از مسیر HTTPS سایت درخواست می‌شود. زیرنویس آنلاین ترجیحاً باید از endpoint HTTPS سایت برگردد.

## توسعه و بررسی

Java 17، Android SDK 36، Gradle 8.13، Android Gradle Plugin 8.13.2 و Media3 1.10.0.

```bash
./gradlew testMobileDebugUnitTest testTvDebugUnitTest lintMobileDebug lintTvDebug
./gradlew assembleMobileDebug assembleTvDebug
```

برای بررسی پیش از انتشار: پخش MP4/HLS و MKV روی دستگاه هدف، جابه‌جایی شبکه با/بدون VPN، فایل زیرنویس فارسی، مسیر سایت، ادامهٔ پخش بعد از انتخاب فایل، ریموت تلویزیون، صداهای چندزبانه و قابلیت‌های محدود به سخت‌افزار مانند HDR و کدک صوتی را روی دستگاه واقعی امتحان کنید.

منابع رسمی: [Media3](https://developer.android.com/media/media3)، [انتخاب فایل اندروید](https://developer.android.com/training/data-storage/shared/documents-files)، [Android TV](https://developer.android.com/training/tv/get-started/create). مجوز و منشأ فایل‌های جانبی داخل پوشهٔ `licenses` ثبت شده است.
